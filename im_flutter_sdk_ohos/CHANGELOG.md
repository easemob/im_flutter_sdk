## 1.16.0-ohos

### 中文

随主包 `1.16.0-ohos` 一起发布，原生基线升级为 `@easemob/chatsdk` 1.16.0（平版 native 4.26.1 开发基线），以 ohpm 版本号依赖接入。

**新增**（chatsdk 1.16.0 新能力的 wrapper 平版，详见主包 CHANGELOG）

- `ClientWrapper` 新增 `getConnectionState` 路由（`isConnected` 保留）；`MethodKeys.ets` 由 `tool/check_method_keys.py --generate` 重新生成；
- `ConversationWrapper` 新增 `markMessagesAsReadWithTimestamp` 路由；
- `ChatOptionsHelper` 新增 `disconnectNotifyThreshold`、`usePushInBackground` 两个选项的下发；
- 连接监听注册回放与断开通知平滑为原生行为，wrapper 事件链路无需改动。

### English

Shipped together with the main package `1.16.0-ohos`; the native baseline is upgraded to `@easemob/chatsdk` 1.16.0 (ported from the native 4.26.1 development baseline), integrated as a versioned ohpm dependency.

**Added** (wrapper porting of the new chatsdk 1.16.0 capabilities; see the main package CHANGELOG for details)

- `ClientWrapper` adds the `getConnectionState` route (`isConnected` is kept); `MethodKeys.ets` is regenerated by `tool/check_method_keys.py --generate`;
- `ConversationWrapper` adds the `markMessagesAsReadWithTimestamp` route;
- `ChatOptionsHelper` now forwards the `disconnectNotifyThreshold` and `usePushInBackground` options;
- Connection-state replay on registration and disconnect-notification smoothing are native behaviors, so the wrapper event pipeline needs no change.

## 1.15.0-ohos

### 中文

鸿蒙平台实现包首个版本，随主包 `1.15.0-ohos` 一起发布（本包先发布到 pub.dev，主包按精确版本引入）。

**新增**

- 新增 `im_flutter_sdk_ohos` 平台实现包，基于 HarmonyOS 原生 `@easemob/chatsdk` 1.15.0；
- 实现 `im_flutter_sdk_interface` 的全部 MethodChannel 路由，覆盖 `ChatClient` 与 8 个 Manager 的 wrapper（interface 为 pub.dev 已发布 4.25.0，复用，不随本线发版）；
- 新增鸿蒙本地测试入口：仓库根目录 `tool/ci/ohos_local.sh`、`tool/ci/smoke_local.harmony.sh`、`tool/ci/nightly_local.harmony.sh`（smoke 零凭证；nightly 只需长期凭证，token 由脚本现场换取）。

**修复**

- 修复 `ChatClient.init` 后事件监听器未及时注册，导致纯接收方收不到事件的问题；
- 修复 `loadMessagesWithIds`、`searchMsgFromDB` 参数键与 Dart 侧不一致的问题；
- 修复 `getGroupWithId` 对不存在的群返回空壳对象的问题（现返回 `null`）；
- 修复群组/聊天室成员列表缺少群主/房主的问题；
- 修复会话消息分页顺序、按时间删除会话消息参数的问题。

**已知限制**

- 暂不支持 Thread 相关 API（按鸿蒙能力缺口清单移除）；
- 鸿蒙端隐藏悬浮附件面板（`file_picker` 无可用实现）；
- 聊天室消息回执、翻译、语音转文字、服务端消息搜索等依赖服务端增值服务开通。

### English

First release of the HarmonyOS implementation package, shipped together with the main package `1.15.0-ohos` (this package is published to pub.dev first; the main package depends on it by exact version).

**Added**

- Added the `im_flutter_sdk_ohos` implementation package, built on HarmonyOS native `@easemob/chatsdk` 1.15.0;
- Implemented all MethodChannel routes of `im_flutter_sdk_interface`, covering the wrappers for `ChatClient` and 8 managers (interface stays on its published 4.25.0 release and is not republished on this line);
- Added HarmonyOS local test entries under the repository root: `tool/ci/ohos_local.sh`, `tool/ci/smoke_local.harmony.sh`, and `tool/ci/nightly_local.harmony.sh` (smoke needs no credentials; nightly needs only long-lived credentials, with tokens fetched by the script at run time).

**Fixed**

- Fixed event listeners not being registered in time after `ChatClient.init`, which caused receive-only clients to miss events;
- Fixed parameter keys of `loadMessagesWithIds` and `searchMsgFromDB` not matching the Dart side;
- Fixed `getGroupWithId` returning a shell object for a non-existent group (it now returns `null`);
- Fixed group/chat room member lists missing the group owner/room owner;
- Fixed conversation message pagination order and the parameter for deleting conversation messages by time.

**Known limitations**

- Thread-related APIs are not supported yet (removed per the HarmonyOS capability gap list);
- The floating attachment panel is hidden on HarmonyOS (`file_picker` has no available implementation);
- Chat room message receipts, translation, voice-to-text, and server-side message search depend on server-side value-added services being enabled.
