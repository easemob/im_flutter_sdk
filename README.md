# 环信 IM Flutter SDK

English | [中文](#中文)

The Flutter plugin repository for EaseMob IM, built on the Federated Plugin architecture. Supports Android, iOS, and HarmonyOS (HarmonyOS is provided as a plugin in a separate repository).
