# 发版映射检查清单（Android SDK）

1. 锁定版本区间
- 明确起止版本（例如 `4.14.0 ~ 4.16.2`）。
- 若终点版本在该平台发版页不存在，写明“平台无此版本条目”，并按实际最后版本收口。

2. 结构化发版项
- 每条 bullet 拆成单条“可判断”的变更项。
- 保留版本、分类（新增特性/优化/修复）。

3. 覆盖判定
- 已覆盖：存在 strict API case 且断言语义匹配。
- 可补充：cmd/API 已有能力，当前缺 case 或断言不够。
- 当前不可覆盖：SDK 内部实现、性能优化、Demo UI、无稳定外显信号。

4. 文档输出
- 输出“全量变更”表，不遗漏条目。
- 每条都要有覆盖状态和原因。
- 对“可补充”给出建议 case 名称与目标断言点。

5. 标签执行
- pytest marker 使用合法标识符（如 `agorachat1_4_0`）。
- 文档可显示业务标签（如 `agorachat1.4.0`）。
- 验证 `pytest -q -m agorachat1_4_0 --collect-only` 可收集到预期用例。
